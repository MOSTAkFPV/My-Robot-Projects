# My-Robot-Projects
Добро пожаловать в мой репозиторий! Здесь собраны мои практические проекты по робототехнике, автоматизации и электронике, реализованные на базе микроконтроллеров и не только.  Этот репозиторий — мое портфолио, демонстрирующее путь от базовых тестов компонентов до создания сложных систем (включая самодельные устройства радиоуправления).
